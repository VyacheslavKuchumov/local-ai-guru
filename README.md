# Local AI Guru

Локальный помощник для экстренного кодинга и поиска по офлайн-библиотеке под Windows.

Проект для личного некоммерческого использования.

Целевой бюджет всего комплекта — 100 GB на диске, включая данные WSL, модели, среды, библиотеку и временный резерв; установленная Windows не входит. Возможность уложиться в этот объём ещё проверяется. Пользователей — один или максимум двое.

Целевая машина: Ryzen 5 5600X, 16 ГБ RAM, RTX 3060 12 ГБ VRAM.

Требования:

- Инференс через llama.cpp; модели GGUF из Hugging Face.
- Интернет выключен по умолчанию, включается пользователем явной командой.
- VPN не требуется ни приложению, ни пользовательскому компьютеру.
- Настраиваемые белые списки адресов, каталогов и инструментов.
- Локальная документация Rust, Vue, Scala, ZIO и связанных инструментов.
- Локальные Wikipedia, iFixit, рецепты, медицинские материалы, первая помощь и выживание.
- Заранее подготовленные Docker-среды и зависимости для работы без сети.

Проект находится на этапе проектирования. Установщик и приложение пока не реализованы.

Архитектура и этапы реализации: [ARCHITECTURE.md](ARCHITECTURE.md) и [PLAN.md](PLAN.md).

Материалы исследования: [модели](docs/research/models.md), [библиотека знаний](docs/research/knowledge.md), [среды разработки](docs/research/environments.md) и [границы доступа](docs/research/harness.md). Приведённые оценки требуют проверки на целевой Windows-машине.

[Крупные модели и RAM offload](docs/research/offload.md), [инструмент будущих тестов в WSL](scripts/bench-offload/README.md). Прогоны на целевой машине отложены; результаты разработки скрипта не являются замерами моделей.

## Первые проверки в WSL

Выполнить в терминале Linux внутри WSL, где доступны Git и Python 3.9 или новее:

```sh
git clone https://github.com/VyacheslavKuchumov/local-ai-guru.git
cd local-ai-guru
python3 --version
python3 -m unittest discover -s scripts/bench-offload -p 'test_*.py' -v
nvidia-smi
free -h
df -h .
```

Репозиторий приватный: для клонирования нужна авторизация GitHub. Если каталог уже склонирован, вместо повторного `git clone` перейти в него и выполнить `git pull --ff-only`.

Эти тесты используют маленькие синтетические заглушки в `/tmp`, не запускают модели, не устанавливают зависимости и не меняют настройки WSL. `nvidia-smi`, `free` и `df` нужны для начальной диагностики; ошибка `nvidia-smi` сохраняется как результат проверки, а не запускает установку драйвера. Если Git или Python отсутствуют, сначала показать ошибку — автоматических установок нет.

Для настоящего benchmark понадобятся локальные llama.cpp, GGUF и отдельная ведомость занимаемого места. Команды и ограничения описаны в [инструкции runner](scripts/bench-offload/README.md). Успех синтетических тестов подтверждает работу скрипта, а не скорость или вместимость модели.
