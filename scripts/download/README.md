# Подготовка трёх закреплённых наборов

Три команды скачивают только выбранный набор: runtime llama.cpp b11968, Qwen3.5-9B Q4_K_M с mmproj или Gemma 4 E4B-it Q4_K_M с mmproj. Манифест закрепляет источники, редакции, размеры, SHA-256 и дату проверки 2026-10-28. Фоновые и посторонние загрузки, автоматическое обновление метаданных и установка пакетов не выполняются; обычный запуск скачивает только явно выбранный набор.

## Проверить без сети

`--help` показывает параметры, а `--dry-run` печатает только размер, каталог назначения и source URL выбранного набора. Ни команда не открывает сеть и не запускает скачанные бинарники.

```sh
python3 scripts/download/runtime.py --dry-run
python3 scripts/download/qwen.py --dry-run
python3 scripts/download/gemma.py --dry-run
```

Назначения относительно `~/local-ai-guru-data/`:

- Runtime: `runtime/b11968-cuda12.8/`; два ручных имени архивов — ровно `llama.tar.gz` и `cudart.tar.gz`. После проверки SHA содержимое архивов безопасно извлекается прямо в этот каталог, без дополнительного уровня `runtime/`.
- Qwen: `models/qwen3.5-9b/`, оригинальные имена файлов из Hugging Face.
- Gemma: `models/gemma4-e4b/`, оригинальные имена файлов из Hugging Face.

Размеры наборов: runtime **776 895 574** байта; Qwen **6 598 688 544** байта; Gemma **5 967 544 256** байт. Вместе — **13 343 128 374** байта загрузок; распакованный runtime занимает дополнительное место.

## Явная загрузка одного набора

Обычный запуск разрешает сеть только для выбранной команды и только для закреплённых URL в её bundle:

```sh
python3 scripts/download/runtime.py
python3 scripts/download/qwen.py
python3 scripts/download/gemma.py
```

Для Qwen и Gemma используются закреплённые Hugging Face `resolve/<revision>/<filename>` ссылки. Базовая модель издателя и источник конверсии Unsloth указаны отдельными ссылками и редакциями. Apache-2.0 указан отдельно для издателя и конверсии. Runtime llama.cpp относится к MIT; для архива cudart отдельно действуют условия распространения NVIDIA CUDA, со ссылкой на upstream release. Набор нельзя считать полностью MIT.

Скрипт проверяет точный размер и SHA-256. Полный существующий файл принимается только при совпадении обоих значений. Полный повреждённый файл оставляется на месте и вызывает ошибку без удаления или перезаписи. Частичный файл с тем же именем возобновляется через HTTP Range и сохраняется после прерывания. Если сервер не подтверждает правильный диапазон, частичный файл остаётся без изменений. Установка Python-зависимостей, `sudo`, драйверы, CUDA Toolkit, системные и WSL-настройки не меняются.

На каждый bundle ставится эксклюзивная блокировка для этих скриптов. Она не блокирует ручные команды или сторонние процессы. Если вручную скачиваете файл через `curl`, дождитесь завершения либо остановите `curl` и убедитесь, что запись остановилась до запуска соответствующей команды скрипта на тот же путь. Зависшая lock-запись требует ручной проверки, что процесса загрузки нет; скрипт сам её не удаляет.

Runtime архивы распаковываются только после проверки обоих архивов, прямо в `runtime/b11968-cuda12.8/`. Перед сетью команда печатает выбранный bundle, размер, каталог и источники; для каждого файла сообщает старт/resume, проверку и редкий процентный прогресс. Разрешены обычные относительные symlink/hardlink, только если нормализованные цепочки целей остаются внутри архива и цель присутствует. Абсолютные пути, traversal, ссылки-циклы, устройства и записи через ссылку отклоняются. Сначала содержимое распаковывается во временную staging-папку и проверяется на конфликты. Уже имеющиеся идентичные члены используются повторно; изменённые файлы, каталоги или ссылки не заменяются и вызывают отказ. Скрипт ничего не удаляет из пользовательского каталога и не запускает извлечённые бинарники.

Синтетические тесты используют только локальные фикстуры в `/tmp`, без HTTP-сервера, сети и больших файлов. Они проверяют `--dry-run`, выбор bundle, skip/resume/interruption, lock, SHA mismatch, безопасные и escaping archive links, traversal, отсутствие перезаписи изменённых файлов и сохранение исходного содержимого при отказе.
